# Práctica final React — Zona Clásico

Proyecto original con componentes de clase, React Router v6, Axios, refs y Bootstrap.

## Iniciar

1. `npm install`
2. `npm run dev`
3. Abrir la dirección local que muestre Vite

## Pantallas

- Inicio con equipos
- Detalles de equipo
- Jugadores por equipo
- Ficha de jugador
- Buscador por nombre y por equipo
- Listado de apuestas
- Crear apuesta
- Eliminar apuesta

## API

`https://apiejemplos.azurewebsites.net/`

Las rutas se basan en los servicios de los dos proyectos de referencia.
No se ha comprobado en esta sesión la respuesta de la API en directo.

## Nota

La API crea el identificador de apuesta; se envía `idApuesta: 0`.
